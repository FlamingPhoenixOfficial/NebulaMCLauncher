# NebulaMCLauncher

Is a launcher that brings both curseforge and modrinth together in 1 place awhile also respecting the user's privacy and security.

With our launcher we strive to bring proper end to end encryption when it downloads mods / modpacks from either site But we also will have virus total implemented into it but user must provide their own api token for virus total but it will do a freshly scan of mods specially if it poses a risk and if the file is flagged by virus total in a fresh scan it will be removed instantly from the mod pack to provide safety to the user. 

The source code will be public when we are finished fully implementing things. We want to make sure everything is well kept, organized, clean.
